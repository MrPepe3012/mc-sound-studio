# Sound Studio

Convierte un enlace de YouTube en un sonido de Minecraft: recórtalo, ponle nombre y se añade (`.ogg` + `sounds.json`, con stream) a tu resource pack o mod.

**Requisitos:** Windows, Python 3, Edge, `yt-dlp` y `ffmpeg` en el PATH.

**Uso:** doble clic en `Sound Studio.pyw`.

## Créditos

- Hecha completamente con [Claude](https://claude.ai) (Claude Code, de Anthropic).
- Basada en [yt-dlp](https://github.com/yt-dlp/yt-dlp) para la descarga y [FFmpeg](https://ffmpeg.org) para el recorte y la conversión a `.ogg`.
